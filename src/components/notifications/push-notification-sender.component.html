Why don't I see messages in Firebase Console?

Messages sent via the Firebase Admin SDK (which this dashboard uses) do not appear in the "Cloud Messaging" history list in the Firebase Console. That list is exclusively for marketing campaigns sent manually from the Console itself.

To track delivery, please check the Notifications tab in this dashboard, or view the Cloud Functions logs in the Firebase Console.
